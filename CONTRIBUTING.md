# Contributing

1. Read `AGENTS.md`.
2. Keep provider behavior inside adapters or declarative provider definitions.
3. Add tests for domain logic.
4. Never commit credentials.
5. Keep new UI consistent with `docs/12-BRAND-UI-GUIDE.md`.
6. Provider registry contributions must be declarative and must not execute scripts.
7. Do not add third-party logos or marketing claims without documented rights and substantiation.
8. Update third-party notices when adding or upgrading a dependency used in distributed binaries.
