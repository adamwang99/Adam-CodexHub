SECURE KEY POOLS

  • API keys encrypted with Windows DPAPI (CurrentUser)
  • Plaintext keys never persisted to disk
  • Ordered pools: health, cooldown, bounded failover on 429

LOOPBACK GATEWAY

  • Binds only to 127.0.0.1 with a dynamic local token
  • Codex Desktop/CLI point base_url at the gateway
  • Native Codex Account mode bypasses it entirely

TRANSACTIONAL CODEX CONFIG

  • config.toml validated & swapped atomically
  • Backup + rollback keeps config-ACCOUNT.toml safe
  • Activate a provider without breaking the sign-in
