# 12 — Adam CodexHub Brand & UI Guide

## 1. Brand relationship

Adam CodexHub is part of the Adam Dùng AI ecosystem.

It must feel related but more technical and restrained.

## 2. Approved logo

Use:

`assets/adam-codexhub-logo.png`

The approved direction is a simple 2D wordmark.

Do not reintroduce:

- large 3D emblems
- glass-heavy effects
- metallic photorealism
- overly complex circuit symbols
- mascots inside the application chrome

## 3. Palette

Source brand palette:

| Token | Hex | Usage |
|---|---|---|
| Background | `#111111` | main app background |
| Gold | `#D89B2B` | active state, borders, emphasis |
| Cream | `#F8F4E8` | body text |
| White | `#FFFFFF` | primary heading |
| Aqua | `#2FD0C8` | secondary tech status |
| Card | `#181818` | panels/cards |

## 4. UI use of gold

Gold is an accent, not a fill-everything color.

Use for:

- selected navigation item
- active provider
- primary CTA
- thin dividers
- icons
- focus
- important labels

Avoid large gold backgrounds except small badges.

## 5. Aqua use

Use Aqua sparingly for:

- healthy live gateway
- active connection
- sync status
- technology accent

Do not compete with Gold.

## 6. Typography

Windows-native first.

Recommended:

- Segoe UI Variable / Segoe UI
- fallback Arial

Application UI should not use oversized brand typography.

Typical:

```text
Window title: 20–24
Section title: 18
Card title: 15–16
Body: 13–14
Caption: 12
```

## 7. Surfaces

Background:

`#111111`

Panels:

`#181818`

Borders:

subtle neutral border, gold only when active.

## 8. Buttons

Primary:

- dark/gold treatment
- concise labels

Secondary:

- charcoal surface
- subtle border

Danger:

- separate semantic red; do not recolor danger gold

## 9. Cards

Keep cards flat.

Recommended:

```text
radius 8–10
1px border
very subtle shadow
```

Do not use heavy gold hard-shadow inside the desktop application.

The desktop product should be calmer than social/video brand compositions.

## 10. Status semantics

Healthy:

Aqua + text

Warning:

Gold + text

Error:

red + text

Disabled:

neutral gray

Always pair color with icon/text.

## 11. Grid

The gold brand grid from marketing assets should not be permanently visible behind functional screens.

It may be used subtly in:

- splash
- About page
- empty state
- onboarding

Functional screens should remain clean.

## 12. Tone of copy

Professional, concise, technical but understandable.

Prefer:

`3 new models discovered`

Not:

`Amazing! We found 3 incredible new AI models for you!`
